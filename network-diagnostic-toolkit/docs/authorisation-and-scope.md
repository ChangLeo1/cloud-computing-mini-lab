## Approved activities

- Ping of the device's configured gateway
- DNS resolution tests
- Public connectivity tests
- TCP connection tests to explicitly approved host/ports
- Traceroute to approved targets
- Local Windows security posture collection
- Approved repair action(s), if any:

## Explicitly not authorised unless separately approved
- Router/firewall factory reset
- Shared infrastructure configuration changes
- Subnet-wide scanning
- Credential testing
- Packet interception
- Vulnerability exploitation
- ISP account changes

## Deliverables
- Diagnostic report
- Recommendations
- Repair log/snapshot if a repair is approved

"I authorise the named technician to perform the activities above on the listed assets for troubleshooting purposes."
